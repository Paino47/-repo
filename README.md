# 仓库打码

SillyTavern 第三方扩展：用户需要发布聊天截图时，手动打开面板并启用 User / Char 名字遮挡；NPC 名字可选。

- 作者：元素四十七
- 版本：1.1.0

## 功能
- 点击酒馆顶栏「仓库打码」按钮打开设置面板。
- 需要打码时勾选「开启名字打码」；关闭后恢复原样。
- 分别控制 User 名字、当前 Char 名字和 NPC 名字。
- NPC 打码为可选项：尝试识别聊天中不同于 User 和当前 Char 的其他发言者，并允许手动补充名字（每行一个）。
- 可调节模糊强度；尽量兼容动态聊天内容及手机/桌面布局。

## 安装
解压后将「仓库打码」文件夹放入 SillyTavern 的第三方扩展目录（常见位置为 `SillyTavern/public/scripts/extensions/third-party/`），然后在扩展管理界面启用并刷新。不同酒馆版本目录可能略有差异。

## 重要说明
这是视觉模糊，不会删除、改写或加密原始聊天内容。复制文本、查看源码或禁用样式仍可能看到原文。名称识别依赖酒馆当前页面 DOM，不同版本、主题及群聊模式可能需要适配。该版本尚未在你的实际酒馆环境中验证；请先用测试聊天检查 User、Char、NPC 是否正确遮挡，再用于公开发布。头像、图片、状态栏等其他身份信息不会自动全部遮挡。
